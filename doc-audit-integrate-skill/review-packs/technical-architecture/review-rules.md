# 技术架构报告审核规则包

本规则包适用于技术架构报告，不改变平台 `Finding` 与证据契约。

## 审核要点

- 【重大】检查是否存在大量内部术语但缺少名词解释。
- 【重大】检查部署图组件实例数是否与正文可用性模式相符。
- 【重大】检查是否出现不符合部门高可用要求的单体服务或单节点数据库设计。
- 【重大】检查用户数计算是否给出依据且与经验公式相符。
- 【重大】检查业务处理量、数据处理量、存储量，及均值与峰值差异是否完整、合理。

## 视觉判定

- 全文与表格审核必须先完成。
- 图文问题必须同时具有文本和图片证据。
- 纯文本问题不得以“图中未体现”作为问题依据。
- 图像不清晰、事实未知或对象对应不确定时，使用“不确定”并说明局限性。
